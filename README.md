# Mohab Atef El-Refaai — Portfolio

A brutalist editorial portfolio built with Next.js, React, and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Content

- `data/portfolio.ts` — profile, bio, projects, education, skills, domains, and terminal content.
- `data/WhatsApp Image 2026-10-12 at 6.39.13 PM.jpeg` — the source CV used to populate the site.
- `app/globals.css` — the full design system and responsive rules.
- `app/fonts/` — self-hosted Archivo Black, Inter, and JetBrains Mono.
- `public/MohabAtefEl-RefaaiCV.pdf` — the CV served by the download links.
- `scripts/generate-cv.py` — optional one-page CV generator (requires `fpdf2`).

The terminal is a working virtual shell. Try `help`, `neofetch`, `projects`, `sudo`, or the safe `rm -rf /` easter egg.
